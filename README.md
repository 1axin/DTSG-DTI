# DTSG-DTI

DTSG-DTI is a dual-topology model for drug-target interaction prediction. Its architecture is organized around four modules. Multi-View Entity Representation (MVER) maps complementary drug and target inputs into a shared entity space, using molecular and chemical information for drugs and sequence-based information for targets, with contrastive alignment to coordinate the views. Latent Semantic Multi-Frequency Guidance (LSMFG) uses these attributes to define a semantic neighborhood and learns entity-dependent mixtures of structural frequency responses. Relational Diffusion Trajectory (RDT) propagates the representations through the training interaction graph while retaining a sequence of restarted states. Selective Trajectory Encoding (STE) treats this sequence as a short trajectory and applies selective state-space updates to collect useful information across propagation steps. A final decoder combines the drug and target embeddings to score candidate interactions.
